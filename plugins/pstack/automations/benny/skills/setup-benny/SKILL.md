# Set up Benny

These files are read directly by configured tasks; they are not registered plugin skills. Read [triage](../triage-issue-reports/SKILL.md), [reproduce and fix](../reproduce-and-fix-issues/SKILL.md), and the template configuration before setup.

1. Confirm the target repository, source Slack channel, optional operations channel, tracker, triage identity, permitted messages, draft-only GitHub PRs, model choices, and work budgets. Preserve existing configuration. Keep secrets in the configured connector, secret manager, or environment.
2. Copy the pack to `.agents/automations/benny/` only in the requested repository. Review conflicts and preserve destination-only files. Put user-owned configuration, routing, and feature maps outside the pack, for example `.agents/benny/`. Ensure the configured execution environment can read the actual workflow files and pstack skills. This is a workflow directory, not a native automation registry. Do not register the pack as plugin skills.
3. Choose an authorized local [Agent SDK](https://code.claude.com/docs/en/agent-sdk) or [headless CLI](https://code.claude.com/docs/en/headless) route, a requested Antigravity `/automation` sidecar (`~/.gemini/automations/<name>/automation.toml`), or a hosted or webhook-triggered Antigravity workflow. Desktop runs require the app open and the machine awake. A local scheduled run can read configured new reports since its last processing position. Persist that position outside the pack, preserve original thread coordinates, and skip completed reports. Hosted routines support schedule, authenticated API, and GitHub triggers, not an assumed Slack-message trigger. An existing authorized integration may submit one report's coordinates to the API. Supply committed project skills or approved uploaded instructions because hosted routines cannot read local plugins or personal skills. Use a local execution environment for UI reproduction when cloud access cannot meet the control contract. Do not create a polling service.
4. Check the available Slack reads and replies, tracker search and compensation actions, GitHub draft PR creation, and the [control requirements](../reproduce-and-fix-issues/references/control-adapter.md). Keep before/after UI proof when fixing an actual app bug. If the chosen client cannot drive that UI, choose a supported local environment or report the unmet dependency. Do not discard reproduction or replace it with a guessed result.
5. Map actual event or connector data to `source_channel_id`, `ts`, and optional `thread_ts` for one original report. Event runs may batch reports, so handle each separately with its own immutable coordinates. Ignore replies as new reports unless explicitly configured. Read only reports in the requested channel. Never invent trigger field names or a trusted triage identity.
6. Prepare the two prompts from the templates. Include external configuration, workflow instructions, immutable source coordinates, allowed actions, and where to store the processing position. For hosted routines, supply accessible instructions and verify source and connector access. Create or update a task or routine only after the user authorizes scheduling and the specified Slack and tracker actions. Inspect existing matching tasks first and preserve unrelated settings. Keep trigger credentials in the backend. A local plugin path does not supply instructions to a hosted routine.
7. Check one explicitly authorized report through each configured workflow. Read the resulting thread, tracker entry, evidence, and any draft PR. Confirm no source-channel root post, duplicate ticket, competing fix, merge, or deployment occurred. Report missing tools or permissions. Do not enable unattended writes on an assumed capability.

Use separate tasks for triage and reproduction when that matches the requested setup. The repro task waits for the configured trusted triage marker within its budget. The user can also request both workflows in one manual or scheduled run. A draft-only task instruction overrides the ordinary pstack ready-PR preference.
